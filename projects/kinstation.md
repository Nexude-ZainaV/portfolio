# KinStation

**A pet information platform.** An encyclopedia, multi-pet medical history,
first-aid guidance, and directories for clinics and sitters.

**My role:** founder and engineer.

## Engineering notes

- **Stack:** Next.js 16 (App Router), React 19, TypeScript, Prisma for schema
  and migrations.
- **Documentation as a first-class part of the build.** Strategy, research,
  product specs, legal, operations and architecture each have a home in a
  foldered docs tree with a single index, so decisions are written down where
  the next person will look for them.
- Deployed through GitHub Actions.
