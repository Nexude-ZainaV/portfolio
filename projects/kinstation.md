# KinStation

A pet information platform: an encyclopedia, medical history for households
with several pets, first-aid guidance, and directories for clinics and
sitters.

My role: founder and engineer.

## Engineering notes

- Next.js 16 (App Router), React 19 and TypeScript, with Prisma for the
  schema and migrations.
- The docs are part of the build. Strategy, research, product specs, legal,
  operations and architecture each have a folder, and one index ties them
  together, so a decision gets written down where the next person will look.
- Deployed through GitHub Actions.
